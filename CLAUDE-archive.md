# Liver Exec Tours — Website History Archive

*Condensed history moved out of `CLAUDE.md` on 2026-10-27 so the main file stays current-state only. The full, verbatim session log is in the previous version of `CLAUDE.md` (Project copy dated 2026-09-21). Current rules and technical gotchas are in `CLAUDE.md`.*

## Timeline
- **2026-08-14** — Rebuilt the site as "Waterfront" (ivory/navy/brass, Fraunces + Work Sans) before Joe had asked for a rebuild. Lesson: **discuss before building.** Built the scroll-scrubbed video hero from an AI-generated clip (watermark cropped, keyframe on every frame). Hosting decision: manual upload to BigWetFish, not GitHub auto-deploy.
- **2026-08-15** — Title/buttons fade over the video; fixed a header-reveal bug (sentinel div at the wrong scroll position, replaced with the same rect-math as the scrub). After seeing a competitor site, stripped the page to Hero → Fleet → Contact and added the WhatsApp/email hero enquiry bar. Phone set to 07808 299060.
- **2026-08-16** — Mobile pass: GitHub Pages preview, About, FAQ, static mobile hero photo. Root cause of the photo never appearing on mobile: a `display:none` rule outside the desktop media query (equal specificity, later source order).
- **2026-08-25** — Joe felt the site had been "vibecoded"; agreed a reset (desktop hero kept, mobile hero rebuilt as staged fades, CSS/JS hooks renamed, dead CSS removed). Scroll runway 250vh → 200vh. `info@liverexectours.com` forwarder set up. Built the click-to-edit visual editor.
- **2026-08-26** — Palette swapped to porcelain/gunmetal/champagne (derived values for the variables the palette file didn't cover; ~26 hardcoded rgba literals swept; white-on-champagne contrast bug caught and fixed). New About copy; client names anonymised. UK-wide/London wording broadened across About, FAQ and footer. Built the booking-flow prototype (4 steps, WhatsApp/email hand-off, no live pricing or payment).
- **2026-08-26/27 — Maps debugging.** Autocomplete failed for several reasons in sequence: a `loading=async` timing race (fixed with a short poll for `importLibrary`), then the real cause: the key sat in a different Google Cloud project, while the correct `liver-exec-tours` project (Hugh's account) had no billing and no keys. Fixed by working in Hugh's logged-in Chrome (with permission): linked billing, enabled the three APIs, created a correctly restricted key. Later fixes: legacy `componentRestrictions` doesn't exist on `PlaceAutocompleteElement` (use `includedRegionCodes` + `locationBias`; radius capped at 50,000m), and the autocomplete rendering as a black box in dark mode.
- **2026-08-27** — Booking flow merged into `index.html`; PT Serif headline font (after Mukta and IBM Plex Sans Devanagari were tried and dropped); About redesigned into three columns; FAQ block centring fixed (`margin: 0 auto`) while question text stayed left-aligned; hero title/buttons enlarged and "Enquire"/"Get a Quote" renamed "Plan Trip"; mobile title restored to "Liver Exec Tours" (the "LET" wordmark retired). Phone testing found and fixed the `100svh` hero zoom, the FAQ grey block (`background-size: cover`), the Plan Trip off-centre bug on iOS WebKit (grid `min-width:auto`), header button wrapping, and date/time stacking.
- **2026-08-28** — **Site went live** on liverexectours.com: uploaded in four sub-10MB zips into the addon-domain folder (not `public_html`, which belongs to a different site on the same account).
- **2026-09-15 → 20** — Added error handling around the Maps import/Directions calls (a failed import had left the "appears once a key is added" placeholder showing). Shortened Plan Trip from four steps to two; removed the vehicle step and email field (phone put back at Joe's request); one name ("Plan Trip") everywhere; removed the separate Contact section and Supabase form; built the Testimonials section with placeholder quotes (generic attributions; `PLACEHOLDER QUOTES` comment and an upload-guide grep added so they can't be forgotten). Uploaded five changed files on 2026-09-20 (commit `469c861`) after checking the live folder was clean and hash-matched the previous build.
- **2026-09-21** — Handoff: local and GitHub in sync; the `/liverexectours` command rewritten to point at `CLAUDE.md`; local preview server found listening on all interfaces with an unauthenticated write endpoint, stopped and logged.
- **2026-10-19** — Google Business Profile optimised (address hidden, 24-hour hours, cover/logo, Bookings link, products). Site gained the footer "Verified on Google" badge, LocalBusiness JSON-LD and "Bookings taken 24 hours a day" wording (commit `8a54af1`, uploaded via the quick-update flow).
- **2026-10-21 → 27** — Ten-item launch plan agreed; ownership plan changed (3 Oct) to Joe as self-employed main driver (27 Oct: invoicing LET twice a month, one fixed and one variable for driving); project docs audited and refreshed on 2026-10-27.
